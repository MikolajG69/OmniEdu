# Omniedu — frontend starter

## Wymagania
- Node.js 18+ (zalecane Node.js 20+)
- npm

## Uruchomienie
```bash
npm install
npm run dev
```
Otwórz adres wyświetlony w terminalu (zwykle http://localhost:5173).

## Co już działa
- responsywny layout z nawigacją
- dashboard z kartami statystyk
- tworzenie, edycja i usuwanie notatek (stan lokalny w przeglądarce podczas sesji)
- roadmapa: dodawanie zadań i oznaczanie ich jako ukończone
- przykładowy quiz z wynikiem
- ekran AI Scanner jako zapowiedź przyszłej funkcji

## Na później
Logowanie/rejestracja, backend i baza danych, trwały zapis danych, prawdziwa integracja AI i upload zdjęć nie są jeszcze podłączone.
